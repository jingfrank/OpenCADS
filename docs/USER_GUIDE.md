# 芯片图像异常检测系统 - 使用说明

## 快速开始

### 1. 系统部署

```bash
# 克隆项目
git clone <repository_url>
cd Anomaly_Detection_System

# 启动服务
docker-compose up -d

# 访问系统
浏览器打开: http://localhost
```

### 2. 首次使用流程

```
① 上传数据集 → ② 训练模型 → ③ 加载模型 → ④ 开始检测
```

---

## 功能模块

### 📁 图像数据管理

**入口**：左侧导航栏 → 图像数据管理

**操作步骤**：
1. 点击「新建数据集」按钮
2. 输入类别名称（如：正常芯片）
3. 拖拽上传图片文件或 ZIP 压缩包
4. 等待上传完成

**支持格式**：JPG, PNG, BMP, GIF, WebP, ZIP

**注意事项**：
- 训练只需要**正常样本**图像
- 建议每类 50-200 张图像
- 图像尺寸会自动调整为 256×256

---

### 🎓 模型训练

**入口**：左侧导航栏 → 模型训练

**操作步骤**：
1. 选择已上传的数据集
2. 输入模型名称（如：chip_model_v1.pth）
3. 点击「开始训练」
4. 等待训练完成（显示进度）

**训练产物**：
- 模型文件保存在 `models/` 目录
- 自动计算异常检测阈值
- 训练完成后自动加载该模型

---

### 📦 模型管理

**入口**：左侧导航栏 → 模型管理

**功能**：
- 查看所有已训练的模型
- 切换当前使用的模型
- 上传外部模型文件
- 查看当前加载的模型状态

---

### 🔍 实时检测

**入口**：左侧导航栏 → 实时检测

**前置条件**：必须先加载一个模型

**操作步骤**：
1. 点击上传区域或拖拽图像
2. 系统自动进行检测
3. 查看检测结果

**结果说明**：

| 指标 | 说明 |
|------|------|
| 异常分数 | 数值越高，异常可能性越大 |
| 阈值 | 基于训练数据自动计算 |
| 检测结果 | 分数 > 阈值 则判定为异常 |
| 热力图 | 红色区域表示异常位置 |

**结果示例**：
- ✅ **正常**：异常分数 655.12 (阈值 755.10)
- ⚠️ **异常**：异常分数 892.34 (阈值 755.10)

## 常见问题

### Q1: 检测显示「No model loaded」？
**解决**：请先去「模型管理」页面加载一个模型，或先训练一个新模型。

### Q2: 训练很慢？
- CPU 训练较慢是正常的
- 如需加速，可配置 GPU 版本
- 减少训练图像数量可加快速度

### Q3: 阈值如何调整？
目前阈值为自动计算（均值 + 3倍标准差）。如需手动调整，可修改代码中的 `threshold_std_multiplier` 参数。

### Q4: 支持什么图像格式？
支持：JPG, JPEG, PNG, BMP, GIF, WebP

### Q5: 如何备份模型？
模型文件存储在 `backend/models/` 目录，直接复制 `.pth` 文件即可备份。
